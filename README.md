# Road2Resolve Digital

Professional websites for UK tradespeople and home-improvement businesses.

This static website includes Home, the £499 package, a clearly labelled fictional home-renovation demo, About and Contact. Payment terms are 50% upfront and 50% at delivery.

## Run locally

```sh
python3 -m http.server 4173 --directory dist
```

Open http://localhost:4173.

## Update and build

Page content is generated by `build.py`. Styles, interactions and imagery are in `dist/assets`.

```sh
python3 build.py
```

Set `SITE_ORIGIN` to change the canonical URL and sitemap domain. It defaults to https://road2resolve.digital.

## Deploy

Netlify runs `python3 build.py` from the repository root and publishes `dist`. No Node.js dependencies are required. The configuration file sets the base directory, build command and publish directory explicitly.

If Netlify still runs the old Next.js plugin, remove `@netlify/plugin-nextjs` in Project configuration > Developer settings > Build plugins. Plugins installed through the Netlify UI can remain enabled after their repository configuration is removed.

## Contact form

The contact page sends enquiries through FormSubmit to info@road2resolve.digital. FormSubmit may require a one-time inbox activation. Confirm receipt with a test enquiry after deployment.

The demo company and project imagery are illustrative. The prospect email list is not included in this repository.
